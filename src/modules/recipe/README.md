# Recipe 模块 - 食谱时间轴

## 模块概述

Recipe模块是一个精美的食谱时间轴展示页面，采用温暖的厨房主题设计，支持按日期和餐次浏览食谱。

## 目录结构

```
recipe/
├── RecipePage.vue          # 主页面组件
├── components/
│   └── RecipeCard.vue      # 食谱卡片组件
├── mock/
│   └── recipeData.js       # Mock数据
└── README.md               # 模块说明文档
```

## 主要功能

### 1. RecipePage.vue
- **分类侧边栏**（相对布局）：按餐次分类（早餐、午餐、晚餐、甜点、饮品），紧挨主菜单栏显示
- **时间轴布局**：按天分组展示食谱
- **浮动操作按钮**：添加新食谱
- **响应式设计**：移动端隐藏侧边栏，优化内容区域

### 2. RecipeCard.vue
每个食谱卡片包含：
- 食谱图片（悬停缩放效果）
- 收藏按钮（可切换状态）
- 餐次类型标签
- 制作时长
- 食材清单（带复选框，可标记完成）
- 简要步骤
- 查看完整食谱链接

### 3. 交互特性
- ✅ 食材复选框：点击后文字显示删除线并降低透明度
- ✅ 收藏按钮：点击切换填充/空心状态
- ✅ 图片悬停：平滑缩放动画
- ✅ 响应式设计：适配移动端和桌面端

## 布局说明

### Dashboard集成
RecipePage作为子模块集成到LoveDashboard中，映射到"厨房创食记"菜单项：
- 移除了独立的顶部导航栏（使用全局导航）
- 分类侧边栏采用相对布局，避免与全局导航冲突
- 内容区域自动适配主框架的布局

### 响应式行为
- **桌面端（>768px）**：显示左侧分类侧边栏 + 右侧内容区
- **移动端（≤768px）**：隐藏侧边栏，全屏显示内容

## 设计风格

### 配色方案
- 主色调：温暖的橙红色系 (#9a4024, #ba5839)
- 背景色：柔和的米白色 (#fff8f6, #f9f2f0)
- 辅助色：自然的棕褐色系
- 强调色：清新的绿色 (#526447)

### 字体
- 标题：Playfair Display（优雅的衬线字体）
- 正文：Inter（清晰的无衬线字体）

### 视觉元素
- Material Symbols图标
- 圆角卡片设计
- 柔和阴影效果
- 时间轴线条连接

## 使用方式

在 `LoveDashboard.vue` 中已集成：

```vue
<RecipePage v-else-if="active === 'diary'" />
```

通过侧边栏导航切换到"厨房创食记"即可访问。

## 技术特点

1. **组件化设计**：RecipeCard可复用，支持props传参
2. **响应式数据**：使用Vue 3 Composition API
3. **事件通信**：父子组件通过emit进行交互
4. **模块化结构**：清晰的目录划分
5. **Mock数据分离**：便于后续接入真实API
6. **布局兼容**：遵循Dashboard嵌套布局规范，避免定位冲突
